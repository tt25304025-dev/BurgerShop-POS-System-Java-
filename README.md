# Java BurgerShop POS System

A simple console-based Point-of-Sale (POS) system for managing burger orders.  
This project allows users to:

- Place new orders  
- Search customer details  
- Search order details  
- View orders by status (Delivered, Preparing, Cancelled)  
- Update order quantity and status  
- Identify the best customer  
- Auto-generate order IDs  
- Validate customer phone numbers  

This is a beginner-friendly Java project built using only core Java and arrays.

--------------------------------------------------------------

## 🚀 Features

### ✔ Place Order  
- Auto-generate order ID  
- Validate customer phone number  
- Store customer name, order quantity, and value  

### ✔ Search Functions  
- Search by order ID  
- Search by customer ID  
- Identify best customer based on total purchases  

### ✔ Order Management  
- Update order quantity  
- Update order status (Preparing, Delivered, Cancel)  
- View orders categorized by status  

### ✔ Console UI  
- Clean UI with console clearing  
- Loop-based menu navigation
